# Sprint 00 - Doxnira Commerce Baseline

Este documento serve como o mapa oficial e a documentação técnica de baseline para o módulo de E-commerce da Doxnira, consolidando os elementos existentes no repositório na data de referência. O objetivo é mapear recursos que podem ser reutilizados em futuros módulos (Dashboard Commerce, Produtos Marketplace, Anúncios, Pedidos, Preços, etc.), sem implementar nenhuma funcionalidade nesta sprint.

## 🎯 Objetivo
Mapear e documentar o estado atual do código base para guiar as próximas sprints de desenvolvimento do Doxnira Commerce.

## ⚠️ Regras Invioláveis (Não alterar)
*   Schema: `apps/api-js/prisma/schema.prisma`
*   Backend, Frontend, App-Shell e Rotas não devem ser alterados nesta fase.
*   Nenhuma funcionalidade deve ser implementada ou mockada comercialmente.

## 🚀 Próximos Passos
As funcionalidades deverão ser desenvolvidas de acordo com o Backlog Priorizado (ver `BACKLOG-PRIORIZADO.md`).
